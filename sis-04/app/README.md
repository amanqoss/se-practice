# Smart Campus room catalog

From this directory, install packages with `npm install` (or `npm ci` with the committed lockfile). Run `npm run dev` and open the local URL Vite prints. Use `npx vitest run` for the regression and catalog suites. Run `npm run build` to type-check the application and build the production page.

Set the number of attendees and required equipment, choose a matching room, and enter the start and end times. Times use a fictional day with the clock fixed at 09:00. Select “Ends at 24:00” for midnight. The result updates as you change a field.
